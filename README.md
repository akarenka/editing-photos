# Studio Paint Complete

瀏覽器版繪圖與相片編輯器，不需安裝程式。

## 啟動方式

1. 解壓縮 ZIP。
2. 雙擊 `index.html`。
3. 首次使用需連線網路，以載入 React、Tailwind CSS 與 TIFF 編碼器。

也可在 Windows 雙擊 `START_SERVER.bat`，再開啟顯示的本機網址。

## 已實裝功能

- 新增自訂尺寸畫布、上傳圖片
- 鉛筆、橡皮擦、油漆桶填色、滴管、點擊去背與全自動去背
- 文字工具：文字內容、字型、字重、大小、斜體、對齊、文字描邊、背景、拖曳定位與套用至圖層
- 畫筆尺寸、顏色、不透明度、最近使用顏色與自訂色票
- 左側固定顯示滴管與快速色票；較矮螢幕可上下捲動工具列
- 圖層新增、顯示/隱藏、重新命名、透明度、上下排序、複製、向下合併、刪除、全部合併
- 可刪除任一個別圖層：使用該圖層的「刪除」、上方「刪除選取」，或 Delete／Backspace 快捷鍵
- 亮度、對比度、飽和度、色相、模糊
- 復原/重做（最多 25 個狀態）
- 滑鼠及觸控繪圖、平移、縮放、重設視角
- PNG、JPG、TIFF 匯出
- 鍵盤快捷鍵：Ctrl/Cmd+Z、Ctrl/Cmd+Y、Ctrl/Cmd+Shift+Z、Ctrl/Cmd+O、Ctrl/Cmd+S、+、-

## 注意

- 所有圖片均在瀏覽器本機處理，不會自動上傳到伺服器。
- 大尺寸圖片與油漆桶填色需要較多記憶體與處理時間。
- JPG 不支援透明背景，匯出時會自動加入白色背景。
